## 🪟 7 Core Feature Windows

1. **⚔️ Multi-Model AI Arena (`/arena`)**:
   - Seamless Drag & Drop Dual Split (1:1), Tri-Screen Sprint (1:1:1), and Quad Grid (2×2).
   - Pre-loaded with DeepSeek R1, Claude 3.5 Sonnet, ChatGPT-4o, Tongyi Qwen, Kimi, Doubao, etc.
   - Built-in sandbox anti-fingerprinting automation bypass and disk session persistence.

2. **🧠 Independent Chief Arbiter Dual-Round Synthesis Hub**:
   - Isolated dual-pane design: Left Raw Answers Pool vs. Right Live Chief Arbiter.
   - 2-Phase workflow stepper: Round 1 review & dedicated task assignment ➔ Round 2 targeted deepening ➔ Final single masterpiece synthesis.
   - 100% dynamic Industrial Agent System Prompt extraction (Cursor / Cline / Dify).
   - Hardware-level paste simulation for Slate/Lexical rich editors and absolute selector locking for ChatGPT prompt area.

3. **📚 AI Prompt Inspiration Treasury (`/prompts`)**:
   - 11 top global prompt platform direct links.
   - 5 structured high-frequency scenario templates (Novel writing, AI architecture/coding, Midjourney art, Social media copywriting, Academic deep thinking) with dynamic parameter filling and one-click direct jump to Arena.

4. **🌐 Curated AI Catalog & Persistent Auto-Translation (`/`)**:
   - Hundreds of curated AI tools, top-tier open-source novel writing tools (SillyTavern 31k★, AutoNovel, StoryMoss) and Alibaba Tongyi Wanxiang multimodal creative ecosystem.
   - Built-in browser SPA continuous auto-translation into Simplified Chinese across tabs and navigations.

5. **🎬 In-App Video Bookmarking & Native Playback (`/favorites` & `/videos`)**:
   - **One-click bookmarking from built-in browser**: automatically captures high-res thumbnail covers, titles, and platform badges.
   - **Direct in-app playback**: click any card in Favorites to immediately open the embedded player without leaving the app or enduring web ads.
   - 26+ curated video and live streaming platforms.

6. **⚡ Convertio 300+ Format File Converter (`/convert`)**:
   - Embedded Convertio conversion engine inside desktop application.
   - Drag & drop instant conversion across PDF, Word, Excel, PPT, image, audio, and video formats.

7. **💻 Official Drivers & Network Utilities (`/drivers` & `/tools`)**:
   - 22+ PC & GPU driver portals (Lenovo, Dell, ASUS, NVIDIA, AMD) and domestic peripheral firmware links (Mchose, FreeWolf, Inphic, Logitech).
   - Curated fast ping, DNS, IP, and port inspection tools.

## 🚀 Quick Start (Developers)

```bash
# 1. Install dependencies
pnpm install

# 2. Run web dev server
pnpm dev

# 3. Launch desktop app dev mode
pnpm electron:dev

# 4. Local silent update & test
node update-local.js
```
